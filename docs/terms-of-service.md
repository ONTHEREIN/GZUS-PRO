## 二、服务说明

### 2.1 服务性质

本应用是一个**非官方、非营利的学生开源项目**，**仅供学习交流使用**，旨在聚合和优化展示学校教务系统中的信息，让您更便捷地查看课表、成绩、考勤、水电费、通知、考试安排等教务数据。

**请注意：本应用不是学校官方产品，不代表学校立场。** 所有数据的最终权威来源为学校官方系统。

### 2.2 核心功能

| 功能模块 | 功能描述 |
|---------|---------|
| 智能课表 | 今日课程时间线、周视图、ICS日历导出 |
| 成绩查询 | 实时成绩、绩点计算、学分统计 |
| 考勤管理 | 出勤记录查询、缺勤提醒、统计汇总 |
| 考试提醒 | 考试安排同步、考前推送、倒计时 |
| 水电查询 | 实时余额、用量统计 |
| 校园通知 | 教务通知推送、已读标记 |
| 请假系统 | 在线申请、进度追踪、附件上传 |
| 一卡通 | 余额查询、消费记录 |
| 桌面组件 | Android Widget 展示课表/缴费/业务状态 |

### 2.3 服务免费声明

本应用**完全免费**，不包含任何：
- 付费功能或内购
- 商业广告
- 第三方推广内容

### 2.4 服务可用性

- 本应用尽力保证服务的连续性和稳定性，但不对服务的**不间断性、及时性、准确性**作绝对保证
- 学校系统维护、升级或接口变更可能导致部分功能暂时不可用
- 因不可抗力（自然灾害、网络攻击、学校政策调整等）导致的服务中断，我们不承担责任

## 三、用户账号与认证

### 3.1 身份认证

- 您需要使用**广州软件学院统一身份认证系统**的学号和密码登录本应用
- 您应妥善保管自己的登录凭证，**不得将账号出借、转让给他人使用**
- 因您泄露登录凭证导致的一切后果，由您自行承担

### 3.2 账号安全

- 发现账号被盗用或异常登录时，应立即修改教务系统密码并联系我们
- 本应用不会以任何理由索要您的额外身份信息或验证码

### 3.3 登录方式

本应用支持两种登录方式：

| 方式 | 说明 |
|-----|------|
| **办事大厅统一登录（推荐）** | 通过学校 SSO 登录，可使用所有功能 |
| **教务系统密码登录** | 仅访问课表、成绩、考勤等基础教务功能 |
