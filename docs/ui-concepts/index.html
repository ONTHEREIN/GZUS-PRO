OneGZUS / 全应用 UI 方向探索

六版方向与全界面原型

都包含桌面和移动响应式布局、教务核心模块、基础状态与动效。先选视觉方向，再落到 Flutter 实现。

A

清冷效率

白底、细线、蓝绿状态色，适合长期高频使用的教务工作台。

 B

柔和学习

低饱和暖色、轻卡片、圆润控件，更适合移动端学生日常查看。

 B Full

柔和学习 · 全界面

基于方案 B 的完整单页原型，覆盖登录、首页、课表、请假、成绩、一卡通和 Widget。

 C

夜航动效

深色、发光边界、动态数据层，适合更有科技感的全应用换肤。

 D

教务刊物

杂志式排版、强标题、低装饰，用内容层级让校园事务更像一份今日简报。

 E

信号终端

工业风、硬朗网格、高对比状态色，适合强调效率和可读性的控制台界面。

 F

流光校园卡

透明层、柔和折射、悬浮卡片，偏现代移动系统感但保持信息克制。

 F Full

流光校园卡 · 全界面

基于方案 F 的单页完整原型，覆盖登录、首页、课表、请假、成绩、Widget 等主要界面。
