## 引言

OneGZUS（以下简称"我们"或"本应用"）是广州软件学院学生自发开发的开源工具，致力于为在校学生提供便捷的教务信息服务。**本项目仅供学习交流使用**，非学校官方产品。我们深知个人信息对您的重要性，并始终将保护用户隐私和数据安全置于首位。

**本隐私政策将帮助您了解：**

1. 我们收集哪些信息、为什么收集
2. 我们如何使用和存储这些信息
3. 您对自己的信息享有哪些权利
4. 我们如何保护您的信息安全

**请您在使用本应用前仔细阅读本隐私政策。使用本应用即表示您已充分理解并同意本政策的全部内容。**

## 一、信息收集

### 1.1 您主动提供的信息

| 信息类型 | 具体内容 | 收集目的 |
|---------|---------|---------|
| **登录凭证** | 学号、教务系统密码 | 通过学校统一身份认证完成登录 |
| **用户配置** | 记住密码偏好、主题偏好 | 提升使用体验 |

### 1.2 我们代为获取的信息

通过您的授权登录，我们从学校官方系统代为获取以下信息：

| 信息类型 | 具体内容 | 数据来源 |
|---------|---------|---------|
| **学籍信息** | 姓名、学号、院系、专业、班级 | 教务管理系统 |
| **课程信息** | 学期课表、上课时间、地点、任课教师 | 教务管理系统 |
| **成绩信息** | 各科成绩、绩点、学分统计 | 教务管理系统 |
| **考勤信息** | 出勤记录、缺勤次数、考勤统计 | 教务管理系统 |
| **考试安排** | 考试时间、地点、座位号 | 教务管理系统 |
| **生活缴费** | 电费余额、冷水余额、热水余额（仅绑定宿舍） | 后勤管理系统 |
| **校园通知** | 教务通知、学籍通知、选课通知 | 办事大厅 |
| **请假信息** | 请假申请记录、审批状态 | 办事大厅 |
| **一卡通信息** | 校园卡余额、消费记录 | 一卡通系统 |

### 1.3 设备与环境信息

| 信息类型 | 具体内容 | 收集目的 |
|---------|---------|---------|
| **设备标识** | 设备型号、操作系统版本 | 适配优化、问题排查 |
| **网络信息** | IP地址（仅服务端日志、不关联身份） | 安全防护、异常检测 |
| **应用日志** | 功能使用频率、崩溃日志 | 问题修复、体验优化 |

### 1.4 我们**不收集**的信息

- ❌ 您的即时通讯内容
- ❌ 您的相册、通讯录、短信
- ❌ 您的精确地理位置
- ❌ 您的生物识别信息
- ❌ 任何与教务无关的浏览记录

## 三、信息存储与传输

### 3.1 存储规则

| 存储位置 | 存储内容 | 存储时长 |
|---------|---------|---------|
| 服务端内存 | 学校系统会话 Cookies | 会话有效期内（关闭后清除） |
| 服务端内存 | 单点登录临时票据（CAS Ticket） | 完成认证后立即清除 |
| 服务端**不**持久化 | 您的教务系统密码 | — |
| 前端本地存储 | 本系统 sessionId、学生姓名 | 退出登录时清除 |
| 前端本地存储 | 记住密码（可选） | 关闭功能或退出登录时清除 |
| 前端本地存储 | 主题偏好、缓存数据 | 手动清除或卸载应用时清除 |

### 3.2 安全措施

- 🔒 **传输加密**: 所有网络通信使用 HTTPS/TLS 加密
- 🔒 **密码保护**: 密码仅用于学校统一认证流程，不在任何位置持久化存储
- 🔒 **会话管理**: 使用服务端内存会话，关闭后自动失效
- 🔒 **日志脱敏**: 日志中绝不输出密码、Cookie、验证码等敏感信息
- 🔒 **访问控制**: 生活缴费数据仅绑定当前登录学号选择的宿舍，不向他人展示
- 🔒 **数据隔离**: 每位用户只能访问自己的教务数据

### 3.3 第三方SDK

本应用使用以下第三方服务，可能收集设备层面信息：

| SDK/服务 | 用途 | 可能收集的信息 |
|---------|------|--------------|
| **Bugly (腾讯)** | 崩溃监控与分析 | 设备型号、系统版本、崩溃日志 |
| **Shiply (腾讯)** | 热更新与配置下发 | 设备标识、应用版本号 |
| **SharedPreferences** | 本地数据缓存 | 仅存储在本设备，不上传 |

## 附录：技术实现说明

为便于技术审查和理解，我们公开以下数据处理的技术细节：

### 登录流程

```
用户输入学号+密码 → 后端转发至学校统一认证系统
→ 获取CAS票据 → 换取教务系统会话
→ 返回本系统 sessionId 给前端
密码在中转完成后立即丢弃，不落盘
```

### 数据缓存策略

- **服务端**: 学校系统 Cookies 仅存储在内存会话中，进程重启后失效
- **前端**: 教务数据缓存至本地 SharedPreferences，退出登录时清除
- **网络恢复**: 离线时展示缓存数据，网络恢复后自动更新

### 融校云（第三方接口）

- `openid/unionid` 仅配置在后端环境变量中
- 前端接口响应、状态管理、日志中均不输出此信息
