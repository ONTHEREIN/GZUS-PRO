# 软帮手隐私政策

> **版本**：v1.1
> **生效日期**：2026年9月18日
> **适用产品**：软帮手（OneGZUS）Web、Android、iOS 客户端
> **项目仓库**：[github.com/ONTHEREIN/GZUS-PRO](https://github.com/ONTHEREIN/GZUS-PRO)

软帮手（OneGZUS，以下简称“我们”或“本应用”）是广州软件学院学生开发的非官方、非营利开源工具，用于聚合展示个人教务和校园生活信息。本应用不代表广州软件学院，也不替代学校官方系统。

本政策说明我们在提供服务时处理哪些信息、为什么处理、保存在哪里，以及您可以如何控制这些信息。使用账号密码登录前，您需要阅读并同意本政策和《[用户服务协议](./terms-of-service.md)》；您可以拒绝可选权限或随时停止使用相关功能。

## 一、我们处理的信息

### 1. 登录与学校系统数据

| 信息类别 | 具体内容 | 处理目的 |
| --- | --- | --- |
| 账号信息 | 学号、姓名，以及学校系统返回的院系、专业、班级等身份信息 | 身份识别、数据隔离和页面展示 |
| 登录凭证 | 您在账号密码登录时输入的学校账号密码；使用 SSO 时的临时票据和授权码 | 完成学校统一身份认证，建立学校系统会话 |
| 教务信息 | 课表、课程地点/教师、成绩、绩点、学分、考勤、考试安排 | 展示查询、统计和提醒 |
| 办事信息 | 校园通知、公众号文章、请假记录、审批状态、教师查找结果和办事入口 | 展示通知、提交或追踪您主动发起的业务 |
| 校园卡与缴费信息 | 一卡通余额/消费记录，您主动绑定宿舍的电费、冷水和热水信息 | 查询余额、展示消费和低余额提醒 |

学校系统数据的原始权属和最终准确性归学校及相应系统所有。我们只为当前登录账号请求相应功能所需的数据，不向用户展示其他账号或其他宿舍的数据。

### 2. 本地设置、缓存与提醒信息

根据您使用的功能，客户端可能在本机保存：

- 应用会话 ID、学生姓名/学号和登录状态；
- “记住密码并自动登录”开关，以及您选择保存的密码和自动登录凭据；
- 课表、成绩、通知、考试、考勤、缴费等用于离线展示的缓存；
- 主题色、深色模式、字体大小、首页/导航偏好、学期第一周和本地调课设置；
- 通知安装实例 ID、Web Push 订阅、移动端系统推送注册所需的信息；
- 您主动选择的天气位置、反馈文本、联系方式和待上传的文件。

密码、自动登录凭据、学校 Cookie 和学校认证令牌优先使用平台安全存储；普通设置和非敏感缓存使用客户端本地存储。浏览器版本受浏览器自身存储和安全能力约束。

### 3. 设备、网络与诊断信息

为完成推送、资源下发、兼容性处理和安全防护，我们可能处理：

- IP 地址、请求时间、User-Agent、应用版本和构建号；
- Web Push 订阅信息，或 iOS APNs / ActivityKit 的设备令牌；这些令牌用于投递，不用于读取设备内容；
- Android/iOS 的安装实例标识；
- 使用腾讯 Shiply/ResHub 公共资源功能时的设备标识、设备型号、系统版本和应用版本；
- 您在“反馈问题”页面主动提交的联系方式、描述、附件和最近的客户端诊断日志。

诊断日志由客户端在内存中保留有限条目，仅在您主动提交反馈时发送。日志不应包含密码、Cookie、完整令牌或验证码；您也不应在反馈文字或附件中提交这些内容。

### 4. 天气位置

天气功能会在相关平台请求定位权限。您允许后，应用只读取用于天气查询的近似位置，不进行后台持续定位、轨迹记录或位置画像；拒绝权限时使用默认城市或已有缓存。天气查询可能将默认城市或经过精度降低的经纬度发送给天气服务 [wttr.in](https://wttr.in/)。位置不会用于教务身份认证。

### 5. 我们不主动收集的信息

在没有您主动提交或系统功能明确需要的情况下，我们不主动收集即时通讯内容、通讯录、短信、相册全部内容、生物识别信息、精确位置轨迹或与教务无关的跨站浏览记录。相机、相册、麦克风、日历、定位和通知权限只在对应功能需要时使用，且由系统权限控制。

## 二、我们如何使用信息

我们按最小必要原则处理信息，主要用于：

1. 完成学校 SSO 或账号密码认证，并恢复您主动保留的登录状态；
2. 查询和展示课表、成绩、考勤、学分、考试、通知、请假、校园卡和生活缴费信息；
3. 按您开启的设置生成课程、考试、成绩、考勤、通知和低余额提醒；
4. 在您授权后向对应浏览器或设备投递通知，或在 iOS 锁屏/灵动岛等系统界面展示提醒；
5. 保存必要的缓存和个性化设置，支持网络异常时的有限离线查看；
6. 处理您主动提交的反馈、附件和诊断日志，定位故障、修复问题和改进体验；
7. 进行安全防护、限流、异常检测、服务运维和审计。

我们不出售个人信息，不基于教务数据投放广告，不将您的教务信息分享给其他用户，也不使用教务数据进行与本应用功能无关的画像或营销。

## 三、信息存储、保留与删除

### 3.1 本地存储

| 位置 | 内容 | 删除方式 |
| --- | --- | --- |
| 平台安全存储 | 密码（仅在您勾选记住密码时）、自动登录凭据、必要的学校 Cookie/认证令牌 | 取消记住密码、退出登录、撤销登录态或卸载应用 |
| 普通本地存储 | 会话展示信息、主题/布局偏好、通知安装实例 ID和非敏感缓存 | 退出登录会清除认证和账号缓存；普通外观偏好、设备实例标识可能保留到手动清理或卸载 |
| 浏览器 PWA 存储 | Web Push 注册和 Web 应用缓存 | 取消浏览器通知权限、退出登录、清除站点数据或卸载 PWA |

退出登录会清除本机认证材料、账号缓存、推送注册和应用会话，并请求服务端撤销当前应用会话。若您此前单独开启了“后台持续通知”，请在通知设置中关闭该功能，才能同时撤销后台授权并删除服务端保存的后台凭据。

### 3.2 服务端存储

生产服务使用自托管 PostgreSQL。为支持会话恢复、缓存和您主动开启的提醒，服务端可能保存：

- 应用会话元数据和账号关联信息；
- 经 Fernet 加密的学校系统 Cookie/认证令牌；
- 仅在您授权后台持续通知后保存的、经加密的自动登录凭据，以及课表快照、成绩/考勤/考试/通知检查快照和提醒偏好；
- 按账号隔离的教务、通知、天气和缴费缓存；
- 您主动绑定的宿舍、缴费提醒配置和必要的余额缓存；
- Web Push 订阅、iOS 推送/实况活动令牌和安装实例信息；
- 通知中心的投递状态和有限期的通知内容；
- 您主动提交的反馈、可选联系方式、诊断日志和附件。

应用会话按配置的有效期和活跃状态清理；单点登录临时状态通常在完成认证或短期超时后失效；缓存、通知、推送令牌和后台授权由各自的过期/撤销/清理逻辑处理。反馈工单没有固定公开保留期限，会在完成处理、排障和必要的运维周期后由维护者清理或按申请处理。除法律法规或处理安全事件所必需的情况外，我们不会无期限保留不再需要的数据。

服务端不保存明文密码。需要长期后台提醒时，服务端使用加密的自动登录凭据按授权访问学校系统；关闭后台持续通知或撤销对应凭据后，该凭据和配置会被删除或失效。

## 四、第三方服务与信息共享

### 4.1 学校及系统服务

本应用会按您发起的功能访问广州软件学院统一身份认证、教务系统、办事大厅、一卡通或后勤系统。相关请求用于完成您要求的查询或业务办理，学校系统的处理规则和隐私政策由学校及其服务提供方负责。

### 4.2 外部技术服务

| 服务 | 用途 | 可能涉及的信息 |
| --- | --- | --- |
| 腾讯 Shiply/ResHub | Android/iOS 公共资源和配置下发 | 设备标识、设备型号、系统版本、应用版本、资源请求信息 |
| `wttr.in` | 天气查询 | 默认城市或天气功能提供的近似位置 |
| 浏览器 Push 服务、Apple APNs | 在您授权后投递通知 | Push 订阅或设备令牌、通知载荷和投递状态 |
| 自托管腾讯云 Nginx/FastAPI/PostgreSQL | 提供本应用服务 | 登录、教务、配置、缓存、推送和反馈数据 |

我们不会向第三方出售您的信息。除上述为实现功能所需的服务外，只有在法律法规要求、司法/行政机关依法要求、保护用户或公众重大安全利益，或您明确授权时，才会提供相应信息。

## 五、信息安全

我们采取与风险相匹配的措施，包括：

- 生产环境通过 HTTPS/TLS 传输，并限制 API 请求来源和请求体大小；
- 服务端使用加密方式保存学校会话 Cookie、认证令牌和后台凭据，密钥仅由受保护的服务端配置提供；
- 应用会话、学校数据、缓存和推送注册按学号/安装实例隔离，管理后台使用独立权限和审计记录；
- 日志和错误信息脱敏，不记录密码、Cookie、验证码 token、APNs 私钥、VAPID 私钥或公众号 RSS 私有 token；
- 登出、凭据撤销、推送取消注册和过期清理路径会清除或使相应数据失效；
- 代码通过自动化测试、静态检查和发布前健康检查。

互联网不存在绝对安全。若您发现账号异常、信息泄露或安全漏洞，请立即修改学校密码，并通过 [GitHub Issues](https://github.com/ONTHEREIN/GZUS-PRO/issues) 联系我们；请不要公开发布凭据或个人数据。

## 六、您的选择与权利

您可以：

- 在应用内查看账号下已展示的教务数据，并通过学校官方系统申请更正原始数据；
- 关闭记住密码、后台持续通知、课程提醒、通知类别、天气定位和系统通知权限；
- 通过退出登录清除本机认证材料和账号缓存，并撤销当前应用会话；
- 关闭后台持续通知以删除服务端后台授权凭据；
- 通过 GitHub Issues 申请查询、导出、删除或更正由本应用保存的反馈、绑定、缓存和其他可识别数据。为防止误删或冒用，我们可能要求您提供必要的账号归属证明，但不会要求您在工单中提交密码。

由于课表、成绩、考勤、请假和缴费等原始数据由学校系统维护，涉及原始记录的更正或删除应向学校相关系统提出申请。

## 七、未成年人保护

本应用主要面向广州软件学院在校学生。未满18周岁的用户应在监护人指导下阅读并使用本应用；监护人如需了解或处理相关信息，可通过本政策末尾的渠道联系我们。

## 八、免责声明

1. 本应用是学生开发的非官方开源工具，不代表学校立场。
2. 数据可能来自学校系统实时响应或缓存，最终准确性、完整性和业务效力以学校官方系统为准。
3. 学校系统维护、接口调整、网络故障、设备权限、第三方推送或不可抗力可能导致数据延迟、提醒失败或功能不可用。
4. 请妥善保管学号、密码和设备；因您主动泄露凭据、使用非官方系统或安装来源不明的修改版本造成的后果，由相应责任方承担。
5. 本应用不收取费用，不含商业广告或内购，不得用于违法、违规、商业化批量抓取或侵犯他人隐私的活动。

## 九、政策更新

我们会根据功能、法律法规或安全措施的变化更新本政策。重大变化会在应用内、项目网站或开源仓库以适当方式提示，并更新版本和生效日期。更新后的政策自生效日期起适用；若您不同意更新内容，请停止使用相关功能并退出登录。
