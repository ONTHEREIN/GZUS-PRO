## 文档维护原则

新增或修改涉及个人信息、权限、第三方服务和数据保留期限的功能时，应同步检查隐私政策、服务协议、README 和应用内对应文案。不要在文档中写入真实账号、密码、Cookie、令牌、私有 URL 或生产密钥。
