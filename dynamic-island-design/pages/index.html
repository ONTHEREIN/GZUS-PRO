设计规范补充

多事件、隐私、生命周期与跨平台适配规则

1. 多事件优先级与队列

当多个事件同时满足触发条件时，按以下优先级展示；同优先级按触发时间排队。

P1 · 进行中课程 / 考试 立即替换当前，倒计时实时更新
P2 · 上课/下课提醒（前后 15 分钟） P1 结束后接入，15 分钟后自动结束
P3 · 考试 / 业务截止提醒 截止前 24h 内展示，截止后结束
P4 · 成绩 / 考勤 / 业务新通知 展示 4h 或用户查看后结束
P5 · 水电余额 仅在低于阈值或每日 8:00 刷新时展示
iOS：高优先级进入灵动岛，低优先级进入 Minimal 队列；最多同时 2 个 Live Activity。
Flutter：应用内只展示 1 个，其余按 FIFO 排队；最多保留 5 条待展示记录。

2. 进度条计算定义

事件类型 进度含义 计算方式
课程 本节课已进行比例 已过时间 ÷ 课程总时长
考试倒计时 距离考试开始剩余比例 (触发时剩余 - 当前剩余) ÷ 触发时剩余
水电 已移除进度条 三个独立矩形展示，不显示进度
成绩 / 考勤 / 业务 已处理 / 总条数 已读或已处理条数 ÷ 总条数

用户可在「设置 → 隐私 → 锁屏显示」开启；开启后锁屏仅显示事件类型与数量，隐藏具体分数、缺勤科目、水电余额等敏感信息。

5. 事件生命周期

触发

后端检测到事件或前端轮询发现数据变化

展示

进入灵动岛/应用内悬浮卡片/锁屏，按优先级排队

更新

倒计时每秒刷新；内容变化时推送 content-state 更新

结束

事件到期、用户查看、手动关闭或超时后移除

6. Android / 非灵动岛设备适配

应用内悬浮胶囊

与 Flutter 方案一致，顶部悬浮 Compact/Expanded

通知栏卡片

进度条、倒计时、展开后显示完整内容

桌面小部件（可选）

固定显示下一节课/最近考试/水电余额

7. 离线资源说明

当前设计稿使用 Tailwind CDN 与 Lucide CDN 方便预览。正式工程落地时需要：

  • • 将 Tailwind 配置写入项目构建流程（或改用项目内已有的样式系统）
  • • 把 Lucide 图标替换为 Flutter 内建图标或本地 SVG/字体资源
  • • 颜色令牌与 gzus_design.dart 保持一致

8. 按钮交互状态

点击后执行对应导航或操作，并在 200ms 内结束当前灵动岛（除需要持续展示的场景外）。

形态参数

  • Expanded：最大宽 420 px，圆角 26 px，内边距 12 px
  • iOS Dynamic Island：leading 短文本 / center 标题 / trailing 计时 / bottom 图标+正文+进度
  • iOS Lock Screen：水平卡片，leading 图标 + title/body/progress + trailing 倒计时
  • 边框：背景色 alpha 0.10
  • 玻璃表面：前景色 alpha 0.40 + backdrop-blur-xl
  • 进度条：高 5 px，背景为事件色 12% alpha
