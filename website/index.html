关于使用软帮手你可能想知道的事

完全安全。App 使用学校官方统一身份认证登录，不会存储你的教务密码。所有会话数据均加密存储，且仅用于向教务系统获取你的课表、成绩等数据。
是的。课表、成绩、考勤等数据均实时从学校教务系统获取。当教务系统维护或网络不佳时，App 会自动展示最近一次成功获取的数据，并在恢复后自动刷新。
Web 版可以在任何设备的浏览器中使用，包括 iPhone 和 iPad。由于 Apple 开发者账号费用较高，目前暂未上架 App Store，iOS 用户建议收藏 Web 版到主屏幕，体验与原生 App 基本一致。
完全免费。软帮手（OneGZUS）是学生自发开发的开源项目，所有功能均免费使用，没有任何广告或内购。
欢迎通过 GitHub Issues 提交反馈，或在项目中找到联系方式直接联系开发者。我们非常欢迎用户的建议和反馈。
