# 移动端界面优化 Spec

## Why
当前应用底栏 7 个 Tab 过于拥挤、顶栏未适配异形屏、课表页功能单一且交互体验不佳、部分页面信息密度不足，整体移动端体验有待提升。参考拾光课程表（shiguangschedule）的课表交互设计，对应用进行系统性移动端优化。

## What Changes
- 底栏 Tab 从 7 个缩减为 4-5 个，其余功能入口移入"更多"页
- 新增用户自定义底栏/更多页内容的功能，偏好持久化到本地存储
- 顶栏适配异形屏安全区域，支持滚动时自动隐藏/显示
- 课表页重构：新增今日课表视图、左右滑动切换周次、周次快速选择器、课程块颜色自定义、课程详情优化
- 增加考勤、考试、成绩等页面的信息密度，适配移动端紧凑展示

## Impact
- Affected specs: 底栏导航、顶栏、课表页、考勤页、考试页、成绩页、学分页
- Affected code: `apps/mobile_web/lib/main.dart`（DashboardShell、MobileNavBar、SchedulePage、AttendancePage、ExamsPage、GradesPage、CreditsPage 及相关组件）

## ADDED Requirements

### Requirement: 底栏 Tab 缩减与"更多"页
系统 SHALL 将移动端底栏 Tab 缩减为最多 5 个，默认显示：课表、考试、成绩、更多。其余功能（个人信息、通知、考勤、学分）放入"更多"页。桌面端侧边栏不受影响，仍显示全部导航项。

#### Scenario: 默认底栏布局
- **WHEN** 用户首次使用应用
- **THEN** 底栏显示 4 个 Tab：课表、考试、成绩、更多
- **AND** "更多"页内显示：个人信息、通知、考勤、学分

#### Scenario: 桌面端不受影响
- **WHEN** 视口宽度 >= 720px
- **THEN** 侧边栏仍显示全部 7 个导航项，无"更多"入口

#### Scenario: "更多"页展示
- **WHEN** 用户点击底栏"更多"Tab
- **THEN** 展示一个网格布局页面，包含所有非底栏的功能入口，每个入口显示图标+标签
- **AND** 每个入口可点击跳转到对应功能页

### Requirement: 用户自定义底栏内容
系统 SHALL 允许用户自定义底栏显示的 Tab 和"更多"页的内容，偏好通过 SharedPreferences 持久化存储。

#### Scenario: 进入自定义编辑模式
- **WHEN** 用户在"更多"页点击编辑按钮
- **THEN** 进入底栏自定义编辑模式，底栏和"更多"页的内容均可拖拽排序和增删

#### Scenario: 添加 Tab 到底栏
- **WHEN** 用户在编辑模式下将"更多"页中的某项拖入底栏区域
- **THEN** 该项出现在底栏，底栏 Tab 数量最多 5 个

#### Scenario: 从底栏移除 Tab
- **WHEN** 用户在编辑模式下将底栏中的某项移除
- **THEN** 该项回到"更多"页

#### Scenario: 偏好持久化
- **WHEN** 用户完成底栏自定义编辑
- **THEN** 自定义布局保存到 SharedPreferences，下次启动时恢复

#### Scenario: 恢复默认
- **WHEN** 用户在编辑模式点击"恢复默认"
- **THEN** 底栏恢复为默认布局（课表、考试、成绩、更多）

### Requirement: 顶栏异形屏适配与自动隐藏
系统 SHALL 优化顶栏设计，适配异形屏（刘海屏/挖孔屏）安全区域，并支持内容滚动时自动隐藏顶栏。

#### Scenario: 异形屏安全区域
- **WHEN** 应用运行在有刘海/挖孔的设备上
- **THEN** 顶栏内容避开系统状态栏区域，使用 SafeArea 或 MediaQuery.padding 正确处理顶部安全边距

#### Scenario: 自动隐藏
- **WHEN** 用户在页面内向下滚动内容
- **THEN** 顶栏以动画形式向上滑出隐藏（时长 200ms），为内容区腾出更多空间

#### Scenario: 自动显示
- **WHEN** 用户向上滚动内容
- **THEN** 顶栏以动画形式向下滑入显示（时长 200ms）

#### Scenario: 顶栏精简设计
- **WHEN** 顶栏显示
- **THEN** 移动端顶栏高度不超过 48dp，显示当前页面标题 + 学期/周次摘要，筛选工具收入溢出菜单

### Requirement: 课表页今日视图
系统 SHALL 在课表页新增"今日"视图，展示当天课程的时间线列表，参考拾光课程表的今日课表设计。

#### Scenario: 切换到今日视图
- **WHEN** 用户在课表页点击"今日"Tab
- **THEN** 展示当天课程的时间线列表，每门课显示课程名、教室、教师、上课时间段

#### Scenario: 今日视图与周视图切换
- **WHEN** 课表页顶部提供"今日"/"周课表"切换
- **THEN** 用户可在两种视图间自由切换，切换状态不随页面重建丢失

#### Scenario: 今日无课程
- **WHEN** 当天没有课程
- **THEN** 显示空状态提示"今天没有课程 🎉"

### Requirement: 课表页左右滑动切换周次
系统 SHALL 支持在周课表视图中左右滑动切换周次，参考拾光课程表的交互设计。

#### Scenario: 左滑切换到下一周
- **WHEN** 用户在周课表视图中向左滑动
- **THEN** 课表切换到下一周，带有平滑的滑动过渡动画

#### Scenario: 右滑切换到上一周
- **WHEN** 用户在周课表视图中向右滑动
- **THEN** 课表切换到上一周，带有平滑的滑动过渡动画

#### Scenario: 周次指示器
- **WHEN** 课表页顶部显示当前周次
- **THEN** 点击周次标题弹出底部选择器，可快速跳转到任意周次
- **AND** 底部选择器中标记当前日期所在周

### Requirement: 课表页课程块颜色自定义
系统 SHALL 允许用户自定义课程块颜色，参考拾光课程表的课表个性化配置。

#### Scenario: 修改课程颜色
- **WHEN** 用户在课程详情弹窗中点击颜色选择区域
- **THEN** 弹出颜色选择器，提供预设色板和自定义颜色输入
- **AND** 选择后立即应用到课表视图

#### Scenario: 颜色偏好持久化
- **WHEN** 用户修改了课程颜色
- **THEN** 颜色映射保存到 SharedPreferences，格式为 `schedule.color.{courseNameHash} = #RRGGBB`

### Requirement: 课表页课程详情优化
系统 SHALL 优化课程详情弹窗的移动端展示，增加信息密度和可操作性。

#### Scenario: 课程详情弹窗
- **WHEN** 用户点击课表中的课程块
- **THEN** 弹出底部 Sheet（非居中 Dialog），展示课程完整信息：课程名、教师、教室、周次、节次、课程性质
- **AND** 底部 Sheet 从底部滑入，高度不超过屏幕 70%

#### Scenario: 课程颜色快捷修改
- **WHEN** 课程详情底部 Sheet 展示时
- **THEN** 顶部显示当前课程颜色圆点，点击可快速修改颜色

### Requirement: 移动端信息密度提升
系统 SHALL 增加考勤、考试、成绩、学分等页面的信息密度，使其更适合移动端紧凑展示。

#### Scenario: 考勤页紧凑布局
- **WHEN** 用户在移动端查看考勤页
- **THEN** 考勤概览使用紧凑的横向指标条（正常率进度条 + 关键数字），而非多个 InfoTile
- **AND** 各课程考勤使用紧凑行卡片，每行显示：课程名 | 正常/迟到/旷课/请假 数字

#### Scenario: 考试页紧凑布局
- **WHEN** 用户在移动端查看考试页
- **THEN** 考试条目使用紧凑行卡片，每行显示：课程名 + 时间 + 地点，补考标记用小标签
- **AND** 即将到来的考试置顶并高亮

#### Scenario: 成绩页紧凑布局
- **WHEN** 用户在移动端查看成绩页
- **THEN** 成绩条目使用紧凑行卡片，每行显示：课程名 + 成绩 + 学分 + 绩点
- **AND** 补考记录使用折叠展开，而非独立的 Expander

#### Scenario: 学分页紧凑布局
- **WHEN** 用户在移动端查看学分页
- **THEN** 学分概览使用紧凑的进度条 + 数字展示
- **AND** 必修/选修/其他使用紧凑的横向条形图，而非表格

## MODIFIED Requirements

### Requirement: MobileNavBar
原 MobileNavBar 固定显示 7 个 Tab。修改后：
- 最多显示 5 个 Tab（含"更多"）
- Tab 内容由用户自定义偏好决定
- "更多"Tab 固定出现在最后一个位置（不可移除）
- 每个 Tab 按钮样式优化：选中态使用更明显的底部指示条 + 颜色变化

### Requirement: DashboardShell 顶栏
原顶栏固定显示，包含图标 + 学生名 + 学期/周次 + 筛选工具。修改后：
- 移动端顶栏高度精简至 48dp
- 筛选工具（学年/学期选择、深色模式、退出）收入溢出菜单
- 支持滚动时自动隐藏/显示
- 正确处理顶部安全区域

### Requirement: SchedulePage
原 SchedulePage 仅支持周课表视图 + 工具弹窗。修改后：
- 新增"今日"/"周课表"视图切换
- 周课表支持左右滑动切换周次
- 周次标题可点击弹出底部选择器
- 课程详情改为底部 Sheet
- 支持课程颜色自定义
- 课表工具入口移至顶栏溢出菜单

### Requirement: TimetableView
原 TimetableView 使用 Stack + Positioned 定位。修改后：
- 支持水平滑动手势检测
- 课程块点击改为弹出底部 Sheet
- 课程颜色优先使用用户自定义颜色，回退到 hash 色板

## REMOVED Requirements
（无移除项）
